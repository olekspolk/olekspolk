### Vuelor

[**vuelor.dev**](https://vuelor.dev) — an accessible, headless color picker for Vue 3. A root
that owns state and context plus independent parts consumers assemble freely; three theming
modes from one engine; typed ESM builds, semver releases, and a curated changelog. Distributed
both as an npm package and a shadcn-vue registry, with VitePress docs, `llms.txt`, and an
authored MCP skill so coding agents install and compose it correctly.
